    # Projeto 1 — Testes Manuais | SauceDemo

## 1. Objetivo

Este projeto tem como objetivo praticar testes manuais de software através da validação das principais funcionalidades da aplicação [SauceDemo](https://www.saucedemo.com/), incluindo o login, o carrinho de compras e o processo de checkout.

O projeto demonstra competências de elaboração de casos de teste, execução de testes, registo de resultados e documentação de evidências.

## 2. Aplicação testada

- **Aplicação:** SauceDemo
- **URL:** https://www.saucedemo.com/
- **Tipo de teste:** Testes manuais funcionais
- **Ferramentas:** Navegador web e Markdown para documentação

## 3. Âmbito dos testes

Foram preparados e executados 10 casos de teste, abrangendo:

- Login com credenciais válidas e inválidas
- Validação de campos obrigatórios no login
- Verificação de utilizador bloqueado
- Adição e remoção de produtos do carrinho
- Finalização de uma compra
- Validação dos campos obrigatórios no checkout

## 4. Estrutura do projeto

- `bugs/` — registo de defeitos identificados
- `evidence/` — evidências da execução dos testes
- `testcases/` — casos de teste e respetivos resultados
- `PLAN.md` — plano de testes
- `README.md` — apresentação e descrição do projeto

## 5. Resultados

Os resultados de cada teste estão documentados nos respetivos ficheiros, com o estado **PASS** ou **FAIL**, de acordo com o resultado obtido durante a execução.

As evidências disponíveis encontram-se na pasta `evidence/`.

## 6. Observações

Este projeto foi desenvolvido para fins de aprendizagem e demonstração de competências de QA Manual, utilizando uma aplicação de demonstração.
