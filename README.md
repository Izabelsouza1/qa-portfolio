## 🧪 Projetos

### 1. Manual Testing — SauceDemo

Projeto de testes manuais realizado na aplicação SauceDemo.

**Atividades realizadas:**
- Elaboração de casos de teste.
- Execução de testes funcionais.
- Validação de cenários positivos e negativos.
- Identificação e documentação de bugs.
- Organização de evidências dos testes.
- Elaboração de plano de testes.

### 2. API Testing — ServeRest

Projeto de testes de API utilizando Postman e a API pública ServeRest.

**Atividades realizadas:**
- Testes dos métodos GET, POST, PUT e DELETE.
- Testes de autenticação e geração de token.
- Validação de códigos de status HTTP.
- Testes de cenários positivos e negativos.
- Criação de scripts de validação no Postman.
- Execução dos testes utilizando o Postman Runner.
- Documentação dos casos de teste.
- Registro de evidências e bugs.

📁 [Acessar projeto](./project2-api-tests-postman/)
